# Python Odyssey

A gamified Python learning universe. This repository is independent of ZENTRIX and all other projects.

## Phase 1 — Foundation
- React + TypeScript + Vite learning portal
- FastAPI backend foundation
- Supabase Auth-ready configuration and profile schema
- Separate Render web services for frontend and API

## Roadmap
1. Foundation and authentication
2. Learning dashboard and curriculum
3. XP, quests, levels, achievements
4. Isolated Python execution environment
5. Adaptive learning, projects, and mentor
6. Community and leaderboards
7. Production hardening and launch checks

Never expose Supabase secret or service-role keys in browser code. Python code submitted by learners will require an isolated execution service before it is enabled.
